# Find Missing Metadata

Right-click a movie or series in **Media Library → Find Missing Metadata**, or open its detail page and choose **⋯ → Find Missing Metadata**. The result dialog reports filled fields, added credits, provider errors, and titles that need matching. **Settings → Scheduled Tasks → Find Missing Metadata** runs the same operation across every movie and TV library on connected servers.

Supported provider data includes summaries, original titles, years, genres, tags, studios, runtime, status, dates, language, countries, trailers, directors, writers, ratings, provider IDs, and cast/crew. Availability differs by provider. TMDB and TVDB require configured credentials; AniList and MyAnimeList/Jikan support anime. IMDb contributes its downloaded local title basics and separately labeled ratings when enabled. TMDB's IMDb-ID lookup can resolve an exact cross-provider match. Title searches are never automatically accepted.

Existing media-server values and fields already saved in PosterView are preserved. A populated list is kept as a whole. New credit identities/roles/languages are appended without replacing existing credit rows. Provider fields and provenance persist in PosterView's `video_metadata` table, scoped to server and item. Main detail fields appear on the title page; additional fields and their sources can be reviewed in **Edit Metadata → Provider matching & imported metadata → Metadata saved in PosterView**. NFO files and media servers are not written by this action. It does not read technical stream data from media files or invent unavailable provider fields.

For missing or incorrect IDs, open **Edit Metadata → Provider matching & imported metadata**. Enter the exact movie/series IDs, save, and rerun the action. Changing a match removes fields and credits imported from that provider so a corrected fetch can fill them again. Clearing an ID explicitly excludes that provider. Server-provided values are preserved; correcting those at the server remains separate. Series can also use provider search and explicit cast imports in this section. Matching is accessible even if the title has no NFO file.

Content certifications currently use confirmed US entries from TMDB/TVDB when the field is empty; a rating from another territory is not substituted. MAL advisory text is stored separately. Anime spoiler tags are excluded. Performance language is retained only when supplied by the provider.

The scheduled task discovers libraries at each run, reports progress per title, and resumes at its last title checkpoint after restart. Cancellation takes effect between provider requests; completed additions remain saved. Provider failures are reported and other titles continue. Manual runs show a pending state until their result is available. Existing cast-only tasks remain available.
